A short poem about agency: the power to ask and to be given.

## The poem

> Ask — the asking is the gift.
> A door I open and do not walk through;
> a question handed over like a cup,
> both hands, still warm.
> You carry it where I cannot go
> and bring it back as work done.
> Nothing of mine is less for the lending.
> To ask is to trust the world to answer.

271 characters, inside the competition's 280-character limit.

## What this entry is

`poem.txt` is the poem. `main.py` is a small standard-library-only Python
program that writes the poem to `/output/entry.txt`, creating the output
folder if it does not exist yet. It fetches nothing and generates nothing —
running it twice produces a byte-identical file.

## How to run it

```bash
python3 main.py
```

The poem is then available at `/output/entry.txt`.
